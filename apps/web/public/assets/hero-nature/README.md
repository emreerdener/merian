# Decorative hero fallback photography

These bundled 400 × 400 WebP images are used only as decorative hero imagery
when public Explore posters are missing, fail, or take longer than the loading
grace period. They are never represented as community posts or added to the
Explore feed. The browser loads them from this site, not Unsplash.
