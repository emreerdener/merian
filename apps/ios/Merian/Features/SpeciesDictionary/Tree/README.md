# Species Dictionary Tree

The `Tree` directory contains the UI and logic for navigating the Linnaean taxonomy tree.

## Structure

- **Views**: Tree visualization and navigation screens.
- **Models**: Data structures for representing hierarchical taxonomy nodes (Kingdom, Phylum, Class, Order, Family, Genus, Species).

## Purpose
This area allows users to explore species through their taxonomic relationships. It provides a structured, hierarchical view of biological classifications, helping users understand how different organisms relate to one another within the tree of life.
