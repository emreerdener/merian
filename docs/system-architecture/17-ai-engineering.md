# 17. AI Engineering & LLMOps

Merian's core inference engine leverages Google's Gemini 2.5 architecture (Flash/Pro) executed exclusively inside serverless Deno Edge closures to protect API keys and rigorously enforce output structures natively.

## Generation Configuration Guardrails

- **Dynamic Token Truncation (Non-Biological Bounds)**: To severely drop API costs and Output Token limits, the structural `merianResponseSchema` was relaxed. Nested biological objects (`taxonomy`, `insight_data`, `diagnostic_comparison`) were completely stripped from the explicit `required: []` array boundaries. A critical `systemInstruction` rule now explicitly enforces Gemini to natively OMIT all of these structures entirely if `is_biological_subject = false`. Because the Native iOS Swift struct `EdgeResponse` dictates these sub-nodes precisely as Optionals (`?`), Swift's `JSONDecoder` beautifully collapses missing dictionaries down seamlessly into `nil`, fundamentally preventing decoder crashes while slicing token footprint exponentially on non-biological payloads!
- **Universal Schema Enforcement**: To aggressively shield core analytical bounds, the Gemini architecture explicitly binds the `merianResponseSchema` structural map across all `isProActive` tier boundaries natively. This forces strict JSON compliance dictating exact object nesting across both Free and Pro models unconditionally natively, ensuring high-fidelity databases and preventing unstructured edge executions globally.
- **Token Throttling (`maxOutputTokens: 800`)**: To aggressively combat LLM hallucination, API cost overruns, and runaway "thinking/planning" tokens structurally introduced by hybrid reasoning models, all production Edge bindings must enforce an explicit `maxOutputTokens: 800` parameter. This statically guarantees the model focuses exclusively on populating the strict JSON output rather than generating lengthy, unbound internal reasoning chains that silently timeout the user's Edge execution limits.
- **Telemetry Pruning Optimization**: Employs an aggressive minification protocol specifically across context bounds sent up by `CaptureTelemetry`. Legacy ephemeral variables (like `cameraPitchDegrees`, `compassHeading`, `relativeHumidity`, `uvIndex`, and `isFlashFired`) were explicitly obliterated and pruned out of the JSON architecture statically saving hundreds of candidate tokens per physical shutter press natively. Structural nodes like `key_differentiators` and descriptive enum schemas inside Deno are forcefully compressed into flat String arrays dynamically formatting API sizes down cleanly.
- **Low Temperature Constraints (`temperature: 0.1`)**: Biological identification must remain rigorously deterministic. The model's entropy bounds are physically hardcoded to `0.1` natively preventing biological hallucination outputs natively.
