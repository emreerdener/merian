# Identification public metric compatibility — 26 September 2026

Status: implemented and locally verified. App-owned assignment remains Gemini.

## Behavior

A private pure database predicate recognizes the recorded configurations that
support the existing Gemini confidence and photographic-quality meanings. Legacy
SQL-null provenance retains its established behavior; literal JSON null,
malformed or unfamiliar present values cannot qualify. The predicate covers the
actual Flash/Pro compatibility and multimodal profiles, including the previously
admitted Pro audio experiment, at qualified policy version 1. A later policy
revision requires explicit compatibility qualification even if profile names are
unchanged. Native generated decoders also reject unknown top-level and
generation fields rather than silently erasing future semantics. These checks do
not claim empirical calibration.

Community detail returns only `ai_confidence_qualified`, never full execution
metadata. Unknown profiles retain the initial suggestion and candidate order,
with all scores null. The Edge route checks that projection before enrichment;
current native UI omits percentages and Flash/Pro labels. The invoker RPC
remains behind authenticated Edge access with an explicit service-only execute
grant. The taxonomy label helper qualifies its existing ltree operators so the
explicit empty search path preserves label semantics. Actual service-role
profile testing also found a missing `user_follows` read grant; only service
SELECT was added.

Field Trip score credit requires compatible metrics. Explicit confirmation or a
corrected species stays independent of confidence and still cannot bypass the
resolved non-human subject requirements. Receipts include metric compatibility,
and the provenance update trigger enters the existing atomic reconciliation. The
forward migration repairs newly ineligible credit using that same locked path,
preserves selected goals, and updates retained receipt revisions.

Public Perfect Lens ignores unfamiliar scores. Automatic reference-image
promotion excludes unfamiliar profiles in both dry-run and live branches,
including confirmed species, because image quality is itself a provider metric.
The next normal refresh disqualifies existing ineligible reference sources.
Source scores and immutable provenance remain unchanged.

## Compatibility and release order

Apply the forward migration before the updated Community Edge producer. The
additive flag is compatible with older response decoders; current iOS tolerates
its absence only for the older Gemini-only response. Before alternate results
can become public, enforce compatible supported readers or a minimum app
version. Restricting new identification requests alone does not protect older
Community readers who can see someone else's result.

This slice does not change production assignments, permissions, numeric Gemini
thresholds, pricing or benchmarks. No paid inference or hosted mutation is
required to validate it. Field Chat/export meaning, provider-aware usage and
cache compatibility remain the following slice. Prospective matched provider
qualification, published recipient disclosures, client compatibility and an
explicit authorized release remain activation gates.
